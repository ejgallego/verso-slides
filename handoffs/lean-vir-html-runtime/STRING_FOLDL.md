# VIR HTML surface compatibility note

While adding `VersoSlides.Pretty.formatHtmlForVir`, the generated package
accepted `String.Internal.foldl` as a registered native extern, but the browser
runtime trapped with `RuntimeError: unreachable` even for:

```lean
formatHtmlForVir (.text "a&b") #[] 40 0
```

The dependency report contained no missing externs. Both a direct
`String.Internal.foldl` escape loop and an explicit recursive loop over
`String.Internal.get` / `next` / `atEnd` trapped. Replacing the loop with four
`String.replace` passes (`&`, `<`, `>`, `"`) works and passes the live JS/VIR
HTML parity smoke test.

This does not block the demo, but it suggests the registered string-iteration
frontier should be exercised through a callback/recursive function in the
browser runtime, not only through straight-line primitive tests.

Reproduction source and package are generated by:

```console
demos/vir-pretty/scripts/assemble.sh
```

The working implementation remains in `VersoSlides/Pretty.lean`; inspect its
history to recover either rejected loop if a minimized VIR fixture is needed.
